# xorcrypt
ファイルに対してランダムに生成したSHA-256ハッシュ値で全体を簡易的にスクランブルするツールです。
コンテンツに対する機械的な解析や自動スキャンを回避することを目的としています。

名前に`crypt`と入っていますがあくまでスクランブル（難読化）するだけであり暗号化ではありません。

**セキュリティ目的では絶対に使用しないでください。**

## Build
```sh
gcc -O3 -lbcrypt -o xorcrypt.exe xorcrypt.c
```

## Usage
```text
Usage: xorcrypt [-e | -d | -a(-a)] [-fv]
  [-w OUTPUT_DIR(AUTO MODE ONLY)]
  [-k RAW_KEY]
  [-x extension name for auto mode(xnc)]
  SRC_FILE_PATH [FILE_PATH ...]
```
* `-e`: 指定されたファイルを難読化するスクランブルモードを強制（非推奨）
* `-d`: 指定されたファイルを復元する復号モードを強制（非推奨）
* `-a`: 拡張子をみて必要な処理を決定する自動モード
* `-f`: 出力先ファイルが既に存在していても上書きします
* `-v`: 処理経過の詳細表示モード
* `-w`: OUTPUT_DIR: 自動モード時に変換されたファイルを出力するディレクトリ
  省略時はカレントディレクトリ。
* `-k`: RAW_KEY: 初期設計時の残骸なので使用しないでください
* `-x`: 自動モード時にファイル状態の判定に使う拡張子
* `SRC_FILE_PATH ...`: 変換対象のファイル

Windowsの右クリックの「送る」から使うことを想定しているので入力ファイルをまとめて渡す形式です。

> [!WARNING]
> 自動モードでの動作しかろくにテストしてないので、多分動くと思うけど今は`-e`/`-d`は使わないでください。

## How it works
- ランダムに生成した文字列からSHA-256ハッシュ値(32文字)を生成
- ファイル全体を生成したハッシュ値を循環させてXOR演算
- 最後にハッシュ値をファイルの末尾に書きこむ

> [!IMPORTANT]
> 復号キーがファイルに含まれているので暗号にはなり得ません。
> 
> 繰り返しになりますが**セキュリティ目的では絶対に使用しないでください。**

## Recovery
構造上、複雑な計算を行っていないためこのツールを失っても復号は難しくありません。
- バイナリエディタなどで末尾の32バイトを取り出す（これが復号キーです）
- この32バイトでファイルの先頭から32バイトずつXOR演算を末尾まで繰り返す
- 終端が32バイトに満たない場合は、ハッシュ値の先頭部分を必要な長さだけ使用する

> [!NOTE]
> 暗号化はパスワードを失うとデータも完全に失われてしまいますが、これはファイル自体にキーが含まれているためそのリスクを回避できます。
> あくまで機械的な解析に対するものであってデータを保護するものではないので可搬性を重視してこの設計になっています。
